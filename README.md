# PI — Plataforma de Gestão de Desenvolvimento Profissional

## Sobre o projeto

A Plataforma de Gestão de Desenvolvimento Profissional é uma solução web
voltada ao acompanhamento e à análise da evolução profissional de colaboradores.

A plataforma permitirá que colaboradores acompanhem seus cursos, treinamentos,
progresso e histórico de desenvolvimento, enquanto gestores poderão visualizar
indicadores e acompanhar a evolução de suas equipes.

## Objetivo

Desenvolver uma plataforma capaz de centralizar informações relacionadas ao
desenvolvimento profissional dos colaboradores e transformá-las em informações
úteis para acompanhamento e tomada de decisão.

## Público-alvo

- Colaboradores
- Gestores
- Administradores

## Principais funcionalidades

- Autenticação de usuários
- Cadastro e gerenciamento de colaboradores
- Organização por setores
- Cadastro de cursos e treinamentos
- Acompanhamento de progresso
- Histórico de desenvolvimento
- Registro de certificados
- Dashboard do colaborador
- Dashboard do gestor
- Indicadores de desenvolvimento

## Arquitetura

O sistema será desenvolvido utilizando arquitetura em camadas, separando
apresentação, controle/API, regras de negócio, persistência e dados.

## Metodologia

O projeto utilizará Scrum para organização das Sprints e um quadro visual
Kanban para acompanhamento do fluxo de trabalho.

## Evoluções futuras

Após a conclusão e validação da versão principal, poderão ser avaliadas
funcionalidades como:

- MARIA — chatbot da plataforma
- MIRA AI
- Integrações com APIs externas
- Jobs para coleta e atualização automática de dados
- Integrações com plataformas de cursos

Essas funcionalidades não fazem parte da entrega principal neste momento.
